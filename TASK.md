с диска). Эталон обновлять (`node tools/game-snapshot.mjs --update`)
только для намеренных поведенческих изменений, отдельным коммитом.

## Правила (кратко, полные — AGENTS.md и карта)

- Комментарии и ответы по-русски.
- Код игры — только `backend/app/static/game/*.js` и `index.html`;
  `cow-skate-standalone.html` не править руками, только генерация.

  `state`/`geometry`, `let` переприсваивает только модуль-владелец.

- Никаких `if (f.type === …)` в движке — диспетчер `FEATURE_TYPES`.
- Типы — JSDoc-импорты из `backend/app/static/game/types.d.ts`.
